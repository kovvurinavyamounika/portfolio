## 🌐 Free 1-Click Hosting Options

### Option 1: GitHub Pages (Recommended)
1. Create a free repository on [GitHub](https://github.com/new).
2. Upload or push these files.
3. Go to **Settings** > **Pages** > select **main branch** and click **Save**.
4. Your website is live for free worldwide!

### Option 2: Netlify Drop
1. Open [Netlify Drop](https://app.netlify.com/drop).
2. Drag and drop this folder (`mouni portfolio`).
3. Your site gets deployed instantly with a free `.netlify.app` URL.
